# 合成测试档案

`synthetic-v4.1.json` 仅供测试，包含 2 个合成国服 UID、5,664 条人工生成的「测试三星武器 / 测试五星角色 / 测试五星武器」记录。

它不是任何人的真实祈愿历史，正常启动不加载，发布目录不复制。

`Verify-Ui.ps1` 通过标准 UIGF 预检和数据库入库流程，写入新的隔离目录，用于验证数千记录下的布局和图表。不要导入个人档案。

synthetic-ui-v4.1.json 是从上述合成序列派生的 UI 测试资料，使用真实物品名称与 ID 便于检查离线图标和分组，但所有祈愿与 UID 均为虚构，export_app 明确为 SYNTHETIC_UI_TESTS_NOT_REAL_RECORDS。它不代表真实账号，不随发布包分发。
