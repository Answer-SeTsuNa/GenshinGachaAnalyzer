# 下载与安装指南

第一次使用，建议选择**安装版**。安装版和便携版功能相同，都已经带齐运行所需文件，无需另外安装 .NET。

| 选择哪一种 | 适合谁 | 下载后怎么打开 |
| --- | --- | --- |
| 安装版（推荐） | 希望像普通软件一样安装、从桌面打开 | 双击下载的安装文件，按中文提示点击“下一步” |
| 便携版 | 希望免安装、放在自己选择的文件夹里使用 | 先将压缩包全部解压，再打开解压文件夹里的程序 |
| 微软商店版 | 希望通过微软商店安装和更新 | 正式上架后，在 Microsoft Store 搜索并安装 |

## 安装版：下载后按提示安装

1. 在[最新发布页](https://github.com/Answer-SeTsuNa/GenshinGachaAnalyzer/releases/latest)的“安装版”一行点击下载。国内下载慢时，可以选择“公益代理 1”或“公益代理 2”；打不开时换另一个渠道。
2. 下载完成后双击安装文件。文件名包含 `Setup`，结尾是 `.exe`，例如 `GenshinGachaAnalyzer-Setup-v版本号-win-x64.exe`。
3. 按中文安装向导点击“下一步”，可以勾选创建桌面快捷方式。安装完成后，从桌面或开始菜单打开“木偶祈愿分析”。
4. 以后升级时，先关闭软件，再下载新版安装文件安装。已有祈愿记录和设置会保留。

## 便携版：先全部解压，再打开程序

“便携版”就是**不用安装，解压成一个文件夹后即可使用**，并不代表祈愿记录会跟着文件夹搬走。

1. 在最新发布页的“便携版”一行点击下载。文件名结尾是 `win-x64.zip`；不要选择含 `source` 的源码包，它是给开发者看的。
2. 找到下载好的压缩包，右键选择“全部解压”（也可能叫“解压到…”），选择容易找到的位置。
3. 解压完成后，打开解压出来的文件夹，双击 **GenshinGachaAnalyzer.exe**。如果电脑隐藏了文件后缀，就找名称为 **GenshinGachaAnalyzer**、带软件图标、类型为“应用程序”的文件。
4. 请保留解压出来的**所有文件和子文件夹**。不要在压缩包预览里直接运行，不要只把一个 EXE 拖到桌面；需要桌面入口时，请给它创建快捷方式。

以后升级：关闭软件，把新版压缩包全部解压到一个新的文件夹，再从新文件夹打开。安装版与便携版在**同一台电脑、同一个 Windows 用户**下共用祈愿档案；换电脑请先在软件“导出”全部账号，再到新电脑“导入 UIGF”。仅复制程序文件夹不能迁移记录。

## 微软商店：正式上架后的安装步骤

**截至 2026-10-16，商店版已通过认证，等待维护者发布，暂未开放下载。** 当前请使用上面的安装版或便携版。商店安装入口保留在下方，正式上架后才可安装；打开时显示不可用并不代表你的电脑有问题。

1. 打开 Windows 开始菜单，搜索并打开 **Microsoft Store（微软商店）**。
2. 搜索 **木偶祈愿分析**，确认发布者为 **答元耐一**。也可以通过[微软商店应用页面](https://apps.microsoft.com/detail/9P34RSKFWZGJ?hl=zh-CN&gl=CN)进入；浏览器询问是否打开 Microsoft Store 时，选择打开。
3. 点击“获取”或“安装”，等待完成后点击“打开”。如商店提示登录，请在微软自己的登录窗口中操作。
4. 以后通过微软商店更新；需要手动检查时，在本软件设置中点击“在商店中检查更新”，或在微软商店的“库 / 下载与更新”里检查。

首发计划免费、仅中国大陆。商店渠道和桌面渠道的版本可能不同，请以实际商店页面为准。商店版与安装版、便携版的档案**不会自动同步**：先在原版“导出”全部账号，再在商店版“导入 UIGF”，核对 UID 和记录数量后再处理旧版。

微软官方帮助：[如何打开 Microsoft Store](https://support.microsoft.com/zh-cn/accounts-billing/how-to-open-microsoft-store-on-windows)、[从 Microsoft Store 获取应用](https://support.microsoft.com/zh-cn/accounts-billing/get-trusted-apps-and-games-from-microsoft-store)。

## 下载渠道与发布（维护者）

桌面版设置页提供安装版和便携版，每种包均可选择公益代理 1（gh-proxy.org）、公益代理 2（ghproxy.net）或 GitHub 直连。代理转发公开 GitHub Release 文件，不是独立托管镜像，服务可能限流或失效；连接失败时切换渠道。

当前安装版本的入口不依赖检查更新成功即可使用。检查更新成功后，只接受与本仓库、版本标签和标准文件名一致、已上传完成且非空的 GitHub 下载资产。新版尚无可用资产时，可通过“查看新版发布说明”进入 GitHub；检查失败时回退当前安装版本的入口，避免继续显示旧的更新下载地址。

代理入口只在用户主动点击时由系统浏览器打开，不自动下载或运行安装包，不传输 UID、Cookie、认证地址或本地档案。商店版不显示桌面下载渠道，继续由 Microsoft Store 更新。

## 后续发布无需手填链接

1. 使用既有构建、测试和打包流程生成新版本。
2. 推送与 Directory.Build.props 一致的版本标签，例如 v0.1.27。
3. GitHub Actions 自动上传资产，并调用 scripts/New-ReleaseNotes.ps1 生成包含安装版/便携版、两个公益代理和直连入口的发布说明。
4. 用户检查更新后，软件自动使用新版本的资产链接。

应用与发布脚本共用 GenshinGachaAnalyzer.Core/Resources/download-proxies.json；只有代理服务变更时才需要维护此配置。普通源码提交不会自动创建 Release，仍需版本标签。

## 渠道验证

scripts/Verify-DownloadProxies.ps1 -Version 0.1.27 会只读取两个渠道各包的前 64 KiB，核对文件类型及可用时的总长度。加上 -FullInstaller 会通过代理 1 完整下载安装包，并与 GitHub 公布的 SHA256 和长度核对。产物保存在 artifacts，不自动运行下载的安装器。

Microsoft Store 更新程序包需要重新提交认证，不能把已批准的旧包直接替换成新二进制。2026-10-16 后台显示 0.1.23 认证通过、准备手动发布；桌面渠道版本独立递增。
