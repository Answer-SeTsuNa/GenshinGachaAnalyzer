# 木偶祈愿分析隐私政策

生效日期：2026-10-15。维护者：木偶（GitHub：Answer-SeTsuNa）。

木偶祈愿分析是非官方的原神祈愿记录管理工具。本工具没有开发者运营的账号服务器，不上传你的祈愿档案、登录凭据、设置、运行日志或冲突日志，不植入广告、埋点或使用行为统计。

## 本地处理与保存

工具在你的电脑处理 UID、祈愿时间、物品名称与 ID、卡池类型，以及导入文件包含的相关字段。数据库、设置、备份、缓存和日志保存在本地数据目录。你可以在设置中打开该目录、创建一致性备份、导出 UIGF，或经完整 UID 确认后清空某个账号。

桌面版默认位于当前用户 AppData/Roaming/GenshinGachaAnalyzer。商店版默认位于当前用户目录下的“木偶祈愿档案”，与应用安装目录分开，卸载应用后保留；需要彻底删除时，由你自行删除该文件夹。不同渠道的档案通过 UIGF 导出 / 导入迁移，工具不会自动读取或搬移另一渠道的数据库。

如果你使用 Windows、云盘或第三方备份软件同步上述文件夹，该同步由相应系统或服务处理，并非本工具主动上传。

## 米游社登录与祈愿获取

使用登录获取功能前，工具会展示隐私说明，由你主动开始。默认使用米游社 App 扫码，也可使用米哈游官方账号网页。账号、密码和验证码由官方页面及服务验证，本工具不收集或保存密码。

工具在内存中使用本次登录返回的临时凭据，读取官方绑定的原神账号列表，在你选择昵称、UID 和服务器后请求官方祈愿记录。认证凭据仅发送至完成上述功能所需的米哈游官方接口，不发送给开发者，不写入设置、档案或诊断日志。取消或结束后结束本次会话，不默认记住登录。

网页登录使用独立 WebView2 隐私会话，禁用密码保存和自动填充，关闭时清理该会话。二维码在本机生成，不经过第三方二维码服务。官方页面、验证码和服务自身的数据处理遵循[米哈游官方隐私政策](https://user.mihoyo.com/#/privacy/agreement)及页面实际展示的协议。

从游戏获取只读取用户选择的国服游戏日志或缓存，不修改游戏文件。粘贴的祈愿链接只用于本次查询，不写入日志。

## 公开资料与版本更新

应用启动后会检查公开卡池资料，距上次成功检查至少 6 小时才自动再次检查；设置中也可手动检查。卡池排期来自 Snap.Metadata 公开仓库，物品资料和新增图片来自米哈游官方养成计算器及官方资源地址。这类请求不携带 UID、Cookie 或登录凭据。

桌面版主动检查应用版本时连接 GitHub；商店版由 Microsoft Store 管理应用更新。打开外部链接时使用相应系统应用。网络服务会因正常连接获知 IP 地址和必要的 HTTP 请求信息，其自身的数据处理遵循相应服务政策：

- [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)

## 日志、安全与联系方式

运行与冲突日志只保存在本地。运行日志隐藏认证凭据；冲突日志可能包含 UID、记录 ID 和祈愿记录差异。向他人提供日志前，请自行检查并删除不希望分享的信息。本工具不会自动发送崩溃报告。

如需咨询或报告隐私问题，请通过[项目 Issue 页面](https://github.com/Answer-SeTsuNa/GenshinGachaAnalyzer/issues)联系维护者。请勿在公开 Issue 中提供密码、Cookie、认证链接、验证码或完整私人档案。政策变更会随项目文档与发布记录公布。
